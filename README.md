## How to publish (GitHub Pages)

1. Go to `https://github.com/beenodgiree/beenodgiree.github.io`
2. Delete the old `index.html`
3. Upload the new `index.html` from this folder
4. Commit. The site updates in 1–2 minutes at https://beenodgiree.github.io/

Everything is in one file. No build step, no dependencies.

## What was deliberately removed and why

| Removed | Reason |
|---|---|
| 「未経験」 | You have 1 year 4 months of real 情報システム experience. This word puts you in the lowest hiring bracket. |
| Node.js, C++, C | Not on your resume. Listing them invites a technical test you cannot pass. |
| 「データベース設計」 as a completed skill | Softened to テーブル設計と基本機能の実装 within the personal project only. |
| 99.2% UPTIME / 128 ASSETS counters | Could be misread as a real production system you operate. |
